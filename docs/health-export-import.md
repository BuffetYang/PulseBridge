# 导入 Apple Health 导出（全量历史）

PulsHealth 免费版只能自动同步 5 类、最近 30 天。**Apple Health 导出导入**是它的补充：
免费、不受类型数量限制、包含全部历史，但需要手动导出一次（可以设置周期提醒）。
目前可导入 Apple 导出中的 **40+ 种指标、睡眠阶段、训练、活动圆环、手腕温度、呼吸紊乱**等。

两条通道可以同时使用：同一份数据会按**内容指纹**去重，不会重复计数。

## 1. 从 iPhone 导出

1. 打开 iPhone「健康」App。
2. 点右上角**头像**。
3. 滑到底部 → **导出所有健康数据**。
4. 选择保存位置（文件 App / iCloud Drive / 发送到微信文件传输助手等）。
5. 把生成的 `export.zip` 传到 Windows 电脑。

> 导出可能需要几分钟，文件可能几百 MB；请保持手机电量充足。iOS 只允许导出它提供给
> 第三方 App 的全部健康数据；部分受限数据（例如某些临床记录）可能不在导出中。

## 2. 在 PulseBridge 导入

1. 打开 PulseBridge → **设置** → **Apple Health 导出导入**。
2. 点 **选择 export.zip 导入**，选中刚传过来的 zip（也支持直接选 `export.xml`）。
   - 中文系统的导出主文件可能叫「导出.xml」，程序会自动识别，不需要改名。
3. 导入会显示进度，可以取消；大型文件可能需要几分钟（约 76 万条记录约 4 分钟）。
4. 完成后会显示：处理记录数、新增样本、去重数量、新增运动、活动圆环、耗时。

导入是**幂等**的：重复导入同一个文件不会重复写入。PulsHealth 已经同步过的样本，
只要内容一致（类型、起止时间、数值、单位、睡眠阶段），也会被识别为重复而跳过。

## 3. 周/月提醒

在同一个卡片里可以设置：

- **每周**：选择周几 + 时间
- **每月**：选择 1–28 号 + 时间
- 开关打开后，到点会通过系统托盘通知提醒你导入新的 `export.zip`
- 设置页会显示「上次导入」和「下次提醒」
- 如果到点时电脑关机，PulseBridge 下次启动后会补提醒（同一次周期只提醒一次）
- 导入成功后会记录时间，下一次提醒从新的周期开始计算

提醒依赖 PulseBridge 正在运行。建议在设置里打开：
- 开机自动启动
- 启动后最小化到系统托盘
- 关闭窗口时最小化到托盘

## 4. 去重与数据量

- 相同内容（类型、起止时间、数值、单位、睡眠阶段）只保留一条，不区分来源。
- 同一场训练按「类型 + 起止时间」去重，兼容 PulsHealth 与 Apple 导出。
- 数据库使用 WAL，导入过程中桌面界面仍可查看已有数据。
- 导入完成后，仪表盘、趋势、运动、AI 数据摘要会立即刷新。
- 数据保留策略（设置 → 数据保留）也会作用于导入的数据；选择「永久保存」最安全。

## 5. 隐私

导出文件包含完整健康数据，传输和保存时请自行注意：

- 导入完成后可以删除 `export.zip`。
- 不要把导出文件上传到不可信的第三方服务。
- PulseBridge 只在本地读取该文件，不会上传。

## 6. 与 PulsHealth 的分工

| | PulsHealth | Apple 导出导入 |
| --- | --- | --- |
| 类型数量 | 免费版 5 类 | 全部 |
| 历史范围 | 免费版 30 天 | 全部 |
| 自动化 | 后台自动 | 手动 + 周/月提醒 |
| 成本 | 免费 | 免费 |

推荐：PulsHealth 负责日常 5 类自动更新；每月（或每周）导入一次完整导出，
补齐其他指标和历史。
